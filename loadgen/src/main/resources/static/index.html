트래픽 폭주

동작: 평소 대비 20배(2,000 req/s) 트래픽을 10초간 한꺼번에 쏟아붓습니다.

배경: 타임세일이나 이벤트로 트래픽이 급증하면, 백프레셔 없이는 모든 요청이 큐에 쌓이고 레이턴시가 폭발합니다.

관찰 포인트: p99 레이턴시가 2초 이내로 유지됩니다. BUSY(503)가 초과 트래픽을 거절하며 시스템을 보호합니다.

🐌

외부기관 슬로우다운

동작: 카드사 응답 시간이 30ms → 100ms → 200ms → 300ms로 점진적으로 느려진 후 복구됩니다.

배경: 외부기관이 느려지면 inflight이 쌓이고, 메모리 고갈 → 전체 장애로 이어지는 연쇄 장애(cascade failure)의 원인입니다.

관찰 포인트: Inflight이 한계까지 차오르면 Admission Control이 BUSY를 발동시켜 연쇄 장애를 차단합니다. 외부기관 복구 후 완전히 회복됩니다.

🔌

세션 끊김

동작: 카드사와의 TCP 연결이 10초마다 강제로 끊어지는 상황을 15초간 만듭니다.

배경: 네트워크 장애는 언제든 발생합니다. 끊어진 세션의 대기 요청은 타임아웃까지 기다리지 않고 즉시 실패 처리(fail-fast)해야 합니다.

관찰 포인트: 대기 요청이 즉시 에러 처리되고, Exponential Backoff로 재연결 후 트래픽이 정상 복구됩니다.

🔀

응답 순서 뒤바뀜

동작: 카드사 응답의 30%가 50~250ms 추가 지연되어 보낸 순서와 다르게 도착합니다.

배경: TCP 멀티플렉싱에서 여러 요청이 하나의 연결을 공유합니다. Correlation-ID 매칭 없이는 응답이 뒤섞여 잘못된 결과가 전달됩니다.

관찰 포인트: 순서가 뒤바뀌어도 8바이트 correlationId로 정확히 매칭됩니다. 오류 0건.
